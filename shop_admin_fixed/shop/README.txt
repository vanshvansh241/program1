CAMPUSSTORE - Stationery & School Dress Shop

Technology:
- HTML
- Normal CSS
- Python Flask
- SQLite database

How to run on Windows:
1. Install Python 3.
2. Open this project folder in VS Code.
3. Open Terminal.
4. Run:
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python app.py
5. Open http://127.0.0.1:5000 in your browser.

Features:
- Home page
- Stationery and school dress categories
- Product listing from SQLite database
- Stock tracking
- Order request form
- Add product admin page
- Responsive design

Note:
The /admin/add page is intentionally simple for a beginner project. For a real shop, add admin login/authentication, proper order tables, payment integration and security validation.
